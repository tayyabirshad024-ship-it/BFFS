# Media assets

The production build expects these files in this folder:

- `hero-video.mp4` — the supplied 1280x720 Day of Beauty video
- `logo.png` — the supplied Bright Future Foundation logo
- `video-poster.jpg` — poster frame for the video

The GitHub connection used to update the source code only accepts UTF-8 text files, so the original binary media cannot be uploaded through that connection. Upload these three files to `public/` from the supplied project assets before deploying.
